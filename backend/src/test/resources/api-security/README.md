# API security test fixtures

`endpoint-inventory.json` is the versioned contract used by
`OpenApiIntegrationTest`. The test builds the endpoint inventory from the
running Spring application and compares it with this resource.

Update the fixture only after reviewing an intentional controller or access
policy change. The comparison must remain strict so an endpoint cannot be
added, removed, or have its access metadata changed without review.

These fixtures belong to the test runtime and must not depend on the ignored
`docs/` directory or on files generated by a previous local test run.
